Performance overlay

FPS and GPU temperature. Right in your game.

A tiny, click-through overlay in the corner of your screen – no game hooks, no injection.

  • FPS and frame time for DirectX 9–12 games
  • GPU load and temperature for NVIDIA, AMD and Intel – no extra drivers
  • VRAM, CPU and RAM usage, optional clock
  • Choose corner, size, background and which values to show
  • Toggle with Ctrl + Alt + H or show it automatically with game mode

PC check

Find the settings that cost you FPS.

GameBoost analyzes your hardware and Windows, scores your PC and fixes what it can – every change can be undone.

  • Windows Game Mode, background recording, mouse acceleration
  • Refresh rate, optimizations for windowed games, power plan
  • Hints for GPU scheduling, old graphics drivers, RAM and disk space
  • Recommended in-game settings for your GPU and monitor: preset, textures, shadows, DLSS/FSR, Reflex, FPS limit

FAQ

Frequently asked questions

Windows shows a warning on launch – is that normal?

Yes. The .exe is not digitally signed, so SmartScreen shows “Windows protected your PC” on first launch. Click More info → Run anyway. The full source code is on GitHub.

Why does the FPS counter need administrator rights?

GameBoost counts frames with Windows event tracing – the same technique as PresentMon – and Windows only allows that for administrators. Everything else (GPU temperature, load, VRAM, CPU, RAM) works without admin rights. In the app, one click restarts GameBoost as administrator.

What does the PC check change – and can I undo it?

Only per-user Windows settings such as Game Mode, background recording, mouse acceleration, refresh rate and windowed-game optimizations. Every change shows an Undo button that restores the original value. Game files are never touched.

Does GameBoost need admin rights?

No. Everything except the optional FPS counter runs with normal user rights. Only programs of your own user account are closed – and only the ones you selected.

What happens if my PC crashes while game mode is on?

On the next start GameBoost automatically restores your previous power plan and notification settings.

Does GameBoost cost anything?

No. GameBoost is free and open source.
