What it does

Game mode

One click closes the background apps you pick, switches to High performance and mutes notifications. Everything is restored afterwards. Profiles can start automatically with your game.

Performance overlay

FPS, GPU load and temperature, VRAM, CPU and RAM in a corner of your screen while you play. Toggle it with Ctrl+Alt+H.

PC check

Scores your PC, fixes Windows settings that cost performance with one click (with undo) and recommends in-game settings for your hardware.

Crosshair

Eight styles including X, square and circle with dot. It sits exactly in the center of your screen, can hide while you aim down sights, and presets can be shared as a code.

Game library

Finds your Steam, Epic Games and Riot games automatically. Start a game with its game mode profile in one click or add any game by hand.

Session reports

Every game mode run is recorded: average FPS, 1% lows, max GPU temperature and load, with charts. A warning pops up in-game when the GPU runs too hot.

Cleanup & memory

Free up RAM from background apps right before you play and clear temp files, crash dumps and shader caches you no longer need.

Your style

Dark or light mode, seven accent colors, on-screen hints for hotkeys, Discord status, profile sharing as files and automatic updates.

FAQ

Windows warns me when I start it.

The app is not digitally signed, so SmartScreen shows a warning the first time. Click More info → Run anyway. The source code is on GitHub.

Installer or portable ZIP?

The installer adds GameBoost to the Start menu and to “Apps & features”, so you can uninstall it like any other app. The portable ZIP runs from any folder without installing. Both contain the same app.

Does it need admin rights?

No. Only the optional FPS counter needs them, because Windows only allows frame counting for administrators. The app can restart itself as administrator with one click.

Why can't I see the overlay in my game?

Overlays only show up when the game runs in borderless window mode, not in exclusive fullscreen.

Is it allowed in games with anti-cheat?

GameBoost does not touch game files or game memory, but some games and tournaments do not allow overlays. Use it at your own risk.

Does it cost anything?

No. It is free and open source.
