Features

Everything you'd otherwise do by hand before playing.

One-click game mode

One button (or hotkey) – GameBoost does the rest. Everything is restored automatically when you turn it off.

Close background programs

Tick whatever gets in the way while gaming – updaters, browsers, tools. Your selection is saved and can be restarted afterwards.

“High performance” power plan

Switches to High performance and remembers your previous plan. On laptops without that plan, “Best performance” mode is used.

No notifications

Windows toasts are suppressed while you play – no pop-ups in the middle of a round.

Profiles & automation

One profile per game. Add the game's .exe – the profile starts automatically with the game and ends when you close it.

Safe by design

System, Windows, security and anti-cheat processes are never closed. After a crash, GameBoost restores everything.

How it works

  1. Download and unzip the ZIP file.
  2. Run GameBoost.exe – no installation needed.
  3. Set up a profile: tick programs, design your crosshair.
  4. Play. GameBoost runs quietly in the system tray.

All shortcuts can be changed freely in the settings.

Borderless window

The overlay is only visible when the game runs in borderless window (windowed fullscreen) mode – not in exclusive fullscreen.

Anti-cheat

Games with strict anti-cheat (e.g. Valorant/Vanguard, FACEIT) or tournaments may disallow overlays. Use at your own risk. GameBoost does not touch games – it only draws its own transparent window.

FAQ

Frequently asked questions

Windows shows a warning on launch – is that normal?

Yes. The .exe is not digitally signed, so SmartScreen shows “Windows protected your PC” on first launch. Click More info → Run anyway. The full source code is available on GitHub.

Does GameBoost need admin rights?

No. Everything runs with normal user rights. Only programs of your own user account are closed – and only the ones you selected.

What happens if my PC crashes while game mode is on?

On the next start GameBoost automatically restores your previous power plan and notification settings.

Where are my settings stored?

In %AppData%\GameBoost – together with the log files. To uninstall, quit GameBoost and delete the .exe and that folder.

Does GameBoost cost anything?

No. GameBoost is free and open source.
