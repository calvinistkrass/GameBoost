## GameBoost 1.3.0 – games, sessions and more

### New
- **Game library:** finds your Steam, Epic Games and Riot games automatically (or add any game by hand). *Play* turns on the linked game mode profile and starts the game; *Create profile* makes game mode start automatically with that game.
- **Session reports:** every game mode run is recorded – average FPS, 1% low, max FPS, max GPU temperature, GPU/CPU load and RAM – with FPS and temperature charts.
- **Temperature warning:** an in-game hint when your GPU gets hotter than your limit (default 85 °C).
- **On-screen hints:** a short note at the top of the screen when you toggle the crosshair, game mode or overlay with a hotkey.
- **Free RAM & cleanup:** free memory of background apps with one click (or automatically when game mode starts) and remove temp files, crash dumps, old logs and shader caches.
- **Crosshair:** three new styles (X, square, circle + dot) and *Hide while aiming* (right mouse button).
- **Light mode and accent colors:** pick dark or light and one of seven accent colors.
- **Share profiles:** export and import game mode profiles as `.gbprofile` files.
- **Automatic updates:** GameBoost checks for new versions on startup. The installed version updates itself in one click; the portable version opens the download page.
- **Discord status (optional):** shows that you are playing with GameBoost in your Discord profile. Needs a free application ID – see the README.

### Download
- **Installer (recommended):** `GameBoost-Setup-1.3.0.exe` – run it and follow the steps. No admin rights needed.
- **Portable:** `GameBoost-1.3.0-win-x64.zip` – unzip anywhere and run `GameBoost.exe`.

> Windows SmartScreen warns on first launch because the `.exe` is not signed → **More info → Run anyway**.

### Notes
- FPS (overlay and session reports) needs GameBoost to run as administrator – the app offers a one-click restart.
- Overlays are only visible in **borderless window** mode, not in exclusive fullscreen.
- Games with strict anti-cheat may disallow overlays – **use at your own risk**.
