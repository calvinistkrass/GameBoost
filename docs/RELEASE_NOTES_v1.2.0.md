## GameBoost 1.2.0 – simpler design

### Changed
- **Simpler, calmer interface:** flat colors instead of gradients and glow effects, a cleaner sidebar without section labels and smaller, quieter headings.
- **Leaner dashboard:** quick toggles, live system stats and your PC score – hardware details now live on the PC check page, hotkeys in Settings.
- New flat accent color across the app, the in-game overlay, the tray icon and the app icon.
- **Website redesigned** to match: one clear page with features, screenshots, FAQ and download.

All features from 1.1.0 are unchanged: game mode, performance overlay (FPS, GPU load and temperature, VRAM, CPU, RAM), PC check and crosshair overlay.

### Download
Download **`GameBoost-1.2.0-win-x64.zip`**, unzip it and run `GameBoost.exe`. No installation needed.

> Windows SmartScreen warns on first launch because the `.exe` is not signed → **More info → Run anyway**.

### Notes
- Overlays are only visible in **borderless window** mode, not in exclusive fullscreen.
- Games with strict anti-cheat may disallow overlays – **use at your own risk**.
