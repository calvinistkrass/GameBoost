## GameBoost 1.0.1 – first release 🎮

Game mode and crosshair overlay for Windows 10/11. No installation, no admin rights, a single `.exe`.

### Download
Download **`GameBoost-1.0.1-win-x64.zip`**, unzip it and run `GameBoost.exe`. .NET does not need to be installed.

> Windows SmartScreen warns on first launch because the `.exe` is not signed → **More info → Run anyway**.

### Features
- **Game mode** with one click or a hotkey: close selected background programs, switch to the “High performance” power plan, turn off Windows notifications, start programs (e.g. Discord) – everything is restored when you turn it off
- **Profiles** per game that turn on automatically as soon as the game is running
- **Safe:** system, Windows, security and anti-cheat processes are never closed; state is restored even after a crash
- **Crosshair overlay:** cross, dot, circle, cross + dot, T-shape – color, size, thickness, gap, outline, offset, live preview
- Pixel-exact center of the selected monitor (multi-monitor, DPI scaling), click-through
- **Presets** and **sharing by code** (`GB1-…`)
- Global hotkeys (default: `Ctrl+Alt+C` crosshair, `Ctrl+Alt+G` game mode, `Ctrl+Alt+N` next preset)
- Keeps running in the tray, optional autostart, English UI (German available)

### Notes
- The overlay is only visible in **borderless window** mode, not in exclusive fullscreen.
- Games with strict anti-cheat (e.g. Valorant/Vanguard, FACEIT) may disallow overlays – **use at your own risk**.
